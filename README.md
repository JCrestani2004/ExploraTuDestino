# ExploraTuDestino

## Descripcion

No sabes a donde viajar o que tienes que saber del pais que quieres visitar?.
Esta app tendra la informacion de varios paises, esta informacion comprende: Poblacion, bandera, capital, clima e incluso podras ver imagenes del pais elegido. Su fin es dar informacion a las personas para que conozcan los paises que visitaran o por curiosidad.

## Tecnologias

- React
- Bootstrap
- react-router-dom
- Apis publicas
